# Exit Strategy

A satirical mobile game about running a Ponzi scheme: grow the fund, skim what you can, read the paper to judge how close the feds are, and get out before they arrive.

**Play:** https://newbieoo7.github.io/exit-strategy/ (best on a phone, or a narrow browser window). English and Türkçe.

## Files
- `ponzi.html`: the game, written as a single-file Claude artifact.
- `index.html` and `play/`: standalone pages built from it by `python build.py`.
- `versions/`: every saved version. `CHANGELOG.md` says what changed in each.
- `i18n/`: Turkish translation sources and notes.
